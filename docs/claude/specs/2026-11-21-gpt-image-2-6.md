# GPT Image 2.6 replaces GPT Image 2

Status: Implemented

## Context

OpenAI retires `gpt-image-2` on 2027-02-10 (Runware notice dated 2026-11-20,
which names GPT Image 2.6 Sunburst and Flare as the replacements). This app ran
GPT Image 2 through Kie and Comet. Both now sell 2.6, so the old entries are
replaced ahead of the date instead of being left to fail on it.

## What changed

- **Kie.** `gpt-image-2` is gone. `gpt-image-2-6-sunburst` and
  `gpt-image-2-6-flare` take its place, each a text and an image variant with up
  to 16 references. Controls: aspect ratio, resolution (1K, 2K, 4K), quality
  (low to max, default medium). No `seed`: the schema is closed and does not
  name one.
- **Comet.** `gpt-image-2` is gone. `gpt-image-2.6-sunburst` (the new Comet
  image default) and `gpt-image-2.6-flare` take its place, text only and
  `metered`, as before.
- **Atlas.** `openai/gpt-image-2.6-{sunburst,flare}/{text-to-image,edit}` are
  added ahead of GPT Image 2.5 Developer, which stays and is not marked
  deprecated: nobody has announced its retirement.
- **Runware.** Not added. See below.

## Why replace now and not on the date

A dated switch would keep a route that is certain to break, and would need a
clock in every place a model is resolved. Replacing now needs none. Nothing in
this change reads the date. If a provider had not offered 2.6, the route would
have had to stay and hide on 2027-02-10; that case did not arise.

## Saved jobs and stored settings

`PAST_KIE_MODELS` (`lib/kie/catalog.ts`) and `PAST_PROVIDER_MODELS`
(`lib/providers/catalog.ts`) keep the label `GPT Image 2` and the filename code
`gpt-image-2` for the retired id, the same idea as `PAST_GEMINI_VIDEO_MODELS`
for Omni 1.1. `jobModelLabel`, `modelFileCode`, the Kie job list and the Kie
result card read them, so a library card, a download name and a spend row made
under GPT Image 2 still say so.

A stored selection moves to Sunburst: `resolveModel` follows `replacedBy` for
Comet, and the Kie workspace reads its preference through `currentKieModelId`.
Without that, a Kie user on GPT Image 2 would have landed on the first row,
Nano Banana Pro. The stored value itself is not rewritten.

A background request that still names `gpt-image-2` is refused as an unknown
model, as any id outside the catalog is. `list_models` shows the new ids.

## Moderation

Kie documents `moderation: auto | low` for 2.6 with **`low` as its default**.
Leaving the key out would send every Standard request at the vendor's loosest
setting, so the Kie rule writes `auto` on Standard and `low` only on a relaxed
text request. Comet's rule moves to the two 2.6 ids unchanged (Standard omits
the key, since Comet's default is `auto`).

## Pricing

No promotion is stored and none has a dated window, so
`lib/providers/model-promotions.ts` is not touched.

- **Kie** bills 2.6 by token and this app reads Kie's cost from the credit
  balance, so there is no catalog rate, as for every Kie model. `quality` is
  sent explicitly because it is what moves the token count.
- **Comet** publishes token rates only. The entries stay `metered` with no
  rate, so the ledger records the cost as unknown, as it did for GPT Image 2.
- **Atlas** meters tokens and its calculator returns an estimate. The catalog
  rate is that quote at `quality: medium`, which `atlas.ts` now sends
  explicitly: $0.0146 an image (the dearest of the sizes sent, rounded up) plus
  $0.0256 for every edit input, the first included. The quote includes Atlas's
  `discount: "80"`, which has no end date, so by the Seedream 5.5 rule it is the
  rate and not a sale.

## Decisions

**Both weights on each provider.** The retirement notice names both, each
vendor prices them the same, and Atlas 2.5 already lists the pair.

**Kie Economy is left out.** It is a different schema at a different price
model, not a replacement for anything this app ran.

**Runware is left out.** This app has no OpenAI model on Runware, so there is
nothing to migrate, and it would need a new settings dialect for a route that
is the dearest of the four (OpenAI list rates, no discount).

**Atlas 2.6 sends exact wide sizes.** 2.5 snaps 16:9, 9:16 and 21:9 because its
1K tier publishes none. 2.6 publishes 2048x1152, 1152x2048 and 2560x1088, and
each quotes under 1024x1024, so one rate still covers every shape.

## Not verified

- Any id by a real request. None was sent.
- Comet's `gpt-image-2.6-flare` has no catalog row of its own. The id comes
  from the pricing note on the Sunburst row.
- That Comet accepts `moderation: low` and this app's sizes on 2.6. Its
  reference page documents them for GPT image models and predates 2.6.
- What a Comet or Kie image actually costs. Both bill tokens and publish no
  per-image figure.
- That Atlas bills the calculator's estimate. It says the charge settles on
  usage. The per-input $0.0256 was quoted for a URL the calculator could not
  read, so a large reference may cost more.
- How long Atlas's 20% discount lasts. Without it the same request is $0.01817.
- That Kie rejects an undocumented field such as `seed`. The schema says so.
- Whether Kie and Comet turn `gpt-image-2` off on 2027-02-10 or earlier.
- Whether GPT Image 2.5 has a retirement date.
